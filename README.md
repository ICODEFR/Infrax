# 🚀 InfraX: Real-Time Infrastructure Intelligence

**InfraX** is a plug-and-play monitoring suite built with Grafana, Prometheus, and Python exporters — integrated with Stripe for metered billing.

## 🔧 Stack Features

| Component             | Description                                 |
|----------------------|---------------------------------------------|
| 📈 Grafana           | 5 production dashboards auto-provisioned     |
| 🧠 Prometheus        | Metrics collection and alerting              |
| 🐍 Python Exporters  | 5 simulated metric generators                |
| 💰 Stripe Billing    | Per-event metering with live usage reports  |
| 🧾 Docker Compose     | Full local deployment with one command       |
